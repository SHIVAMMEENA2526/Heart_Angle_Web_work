# 💛 Heart Angle - Web Showcase & Live Simulator

Welcome to the official web showcase repository for **Heart Angle**, a premium, open-source, cross-platform dating application built on **React Native (Expo SDK 52)**, **TypeScript**, and **Appwrite BaaS**.

👉 **[Launch Live Website & App Simulator](https://shivammeena2526.github.io/Heart_Angle_Web_work/)**

---

## 🎨 About This Repository

This repository contains the production-ready compiled static web bundle and a custom showcase portfolio for **Heart Angle**. 

Instead of hosting a raw web index, this repository features an **Interactive Mobile Device Simulator**:
* **Showcase Landing Page (`index.html`)**: A modern, dark-mode, glassmorphic layout highlighting key app features, technology architectures, and developer milestones.
* **Interactive Swiper Playground**: A mini click-and-drag swiper deck where visitors can swipe mock cards in their browser.
* **Embedded Smartphone Frame (`app.html`)**: Houses the compiled React Native/Expo web client inside a virtual iPhone screen, enabling visitors to navigate through actual active tabs, discover screens, user profiles, and chat boxes in real-time.

---

## 🛠 Compiled Architecture & Routing

The static web bundle was compiled using Expo's universal export engine (`npx expo export -p web`), generating Static Site Generated (SSG) routes for seamless navigation:

* `/index.html` — Custom showcase landing page and live smartphone simulator.
* `/app.html` — The main React Native/Expo universal web client entry point.
* `/discover.html` — Pre-rendered discovery categories.
* `/people.html` — Tinder-style swipe profiles screen.
* `/profile.html` — User settings and tier comparison table.
* `/auth/signin.html` — Appwrite authorization sign-in screen.
* `/auth/signup.html` — Appwrite account registration screen.
